# 国际供应链研究 · 企业地图版

围绕中国进出口贸易、重点子行业、代表企业布局与海外能力建设的研究看板。

浏览顺序：贸易规模 → 子行业筛选 → 企业区域图 → 能力建设。企业详情从地图进入。

- 运行所需脚本、样式、地图和数据均内置于根目录 `index.html`。
- 无需安装依赖、后端或单独的数据服务。
- 其他HTML仅兼容既有入口；GitHub Pages从 `main` 分支根目录发布。
- 企业资料按各自披露时点呈现，样本分布不等同贸易货值或投资优先级。
